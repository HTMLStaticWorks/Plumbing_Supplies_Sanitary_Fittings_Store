Theme & RTL Configuration

The theme dynamically switches via the data-theme attribute on the <html> element:

// Programmatic theme switch:
document.documentElement.setAttribute('data-theme', 'dark'); // or 'light'
localStorage.setItem('aquapro_theme', 'dark');

// Programmatic RTL switch:
document.documentElement.setAttribute('dir', 'rtl'); // or 'ltr'
localStorage.setItem('aquapro_dir', 'rtl');

Form Validation & Backend Integration

All forms are pre-configured with client-side validation using the data-validate="true" attribute. To connect to Formspree or Netlify Forms, simply update the form action:

<!-- Formspree Integration Example -->
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST" data-validate="true">
  <input type="email" name="email" required>
  <button type="submit">Submit</button>
</form>

<!-- Netlify Forms Example -->
<form name="contractor-quote" method="POST" data-netlify="true" data-validate="true">
  <input type="hidden" name="form-name" value="contractor-quote" />
  <input type="text" name="name" required />
  <button type="submit">Submit Quote</button>
</form>
